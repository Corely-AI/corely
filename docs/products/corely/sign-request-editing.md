# Edit a Corely Sign request

Open an unsent request and choose **Edit draft**. The editor saves changes to this request under the same request ID.

Coaching agreements use the signer assigned by their originating workflow.

1. In **Recipients**, add signers or update their names and email addresses. Choose sequential signing to move signers earlier or later. Removing a signer also removes that signer's fields when the draft is saved.
2. In **Place fields**, select a signer and field type, then click the PDF or choose **Add field**. Use the page controls to place fields on other pages. Use the arrow keys to move a focused field, and Shift with the arrow keys to resize it. The color and name identify the assigned signer.
3. In **Request settings**, set an expiry date in UTC and enter the invitation and consent text. Choose **Save draft**. The sender can return later to finish placing fields.
4. Choose **Review and send invitations** when every signer has a required signature field, the expiry is in the future, and the consent statement is present. The preview and send command both use the saved request revision.

## Replace an existing request

Choose **Create replacement draft** from a sent, voided, expired, or declined request. The replacement starts with the original recipients, fields, invitation, and consent. Set a new expiry in **Request settings**. The replacement links back to the original request.

Preparing or editing a replacement leaves the original open. Confirming **Send replacement** closes the original if it is still open, revokes its existing links, and queues invitations for the replacement. Signers complete the replacement separately. Completed requests retain their sealed PDF and evidence.
