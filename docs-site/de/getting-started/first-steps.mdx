Beginnen Sie mit einer aktivierten Funktion für die Arbeit Ihres Teams. Bestehende Kunden-, Rechnungs- und Ausgabenfunktionen bleiben je nach Konfiguration verfügbar; Finanzen sind optional.

Finanzen sind optional. Buchhaltung ist keine Voraussetzung für operative Apps. Sichtbare Funktionen hängen von Workspace-Konfiguration und Berechtigungen ab. Das vorgeschlagene operative Paket wird noch validiert; die langfristige App-Übersicht ist keine Liste verfügbarer Funktionen.

## Optionale Finanzbeispielee

1. Ersten Kunden anlegen
2. Erste Rechnung erstellen
3. Eine Ausgabe erfassen
4. Den Assistenten fuer eine Standardaufgabe testen
